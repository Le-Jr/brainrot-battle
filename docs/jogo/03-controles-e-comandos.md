# 03 · Controles e comandos

> Os navegadores só liberam o som depois da primeira interação. Aperte uma tecla ou clique na tela para começar a música.

## Toque (celular e tablet)

Num aparelho com tela de toque aparecem os controles na tela. No computador eles podem ser ativados pelo botão **TOQUE**, acima da tela. Tocar na tela do jogo também funciona como START nas telas de menu e de cutscene.

- **D-pad de 8 direções:** é uma área só, não quatro botões. Dá para deslizar o dedo entre as direções, então diagonais e comandos como ↓ ↘ → (EX) e → ↓ ↘ (uppercut) funcionam. Um "polegar" mostra para onde o dedo está apontando.
- **Botões em arco de fliperama:** **SOCO** (vermelho), **CHUTE** (azul) e **ESP** (dourado), mais um **START** pequeno. Cada botão aceita um dedo próprio (multitoque). No Android, cada toque dá uma vibração curta.

### Tela cheia no celular

No celular aparece o botão **JOGAR EM TELA CHEIA** embaixo do jogo (o botão **TELA CHEIA** da barra faz o mesmo):

- o jogo ocupa a tela inteira e **deita na horizontal**: onde o navegador permite (Android/Chrome), a orientação é travada em paisagem; onde não permite (iPhone), o jogo gira 90° sozinho se o aparelho estiver em pé;
- os controles ficam **por cima do jogo**, semitransparentes: D-pad à esquerda, botões à direita;
- no canto de cima ficam **✕ SAIR** e o botão de som.

No computador, a tela cheia mostra só o jogo (os controles de toque aparecem se o botão **TOQUE** estiver ligado).

## Botões da página

| Botão | Efeito |
|-------|--------|
| **MÚSICA** | Liga ou desliga a música (os efeitos sonoros continuam). |
| **NARRADOR** | Liga ou desliga a síntese de voz. Fica sincronizado com a opção dentro do jogo. |

## Lista de comandos

Os comandos consideram o personagem virado para a direita (→ = para frente).

| Golpe | Comando | Observações |
|-------|---------|-------------|
| Soco / chute | Soco / Chute | Golpes básicos, médios. |
| Soco forte | → + Soco | Investe para frente. É **alto**: precisa ser defendido em pé. |
| Rasteira | ↓ + Chute | **Baixo**: precisa ser defendido agachado. Derruba. |
| Soco agachado | ↓ + Soco | Rápido, médio, ótimo para começar correntes. |
| Golpes no ar | Soco / Chute no pulo | **Altos**: o rival tem que defender em pé. |
| Uppercut | → ↓ ↘ + Soco | Invencível no começo, lança o rival para um **juggle**. |
| Agarrão | Perto + → + Chute | Não pode ser defendido. Joga o rival para trás. |
| Especial | Especial | Um por personagem (veja [05-personagens.md](05-personagens.md)). |
| Especial EX | ↓ ↘ → + Especial | Gasta **meia barra**: cerca de +30% a +35% de dano, e projéteis 25% mais rápidos. |
| Super | Especial com a barra **cheia** | Tela de corte com o nome do golpe. Versão muito mais forte. |
| Defesa | Segurar para trás | Agachado para golpes baixos, em pé para golpes altos. Os dois funcionam contra os médios. |

## Correntes e cancelamentos

| Depois de… | Pode emendar |
|------------|--------------|
| Soco | Soco, chute, soco agachado, rasteira, soco forte, uppercut |
| Soco agachado | Soco agachado, rasteira, soco, uppercut |
| Chute ou soco forte | Uppercut |
| Soco, soco agachado, chute, soco forte **que acertou** | Especial, EX ou Super (cancelamento) |

O jogo guarda o último botão apertado por **10 frames**, então dá para apertar um pouquinho antes do golpe acertar.
